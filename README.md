# ImmoCoco

Application web de gestion locative (location meublée) : loyers, quittances, bail, états des lieux, coffre-fort de documents, impôts.

- Page unique (`index.html`), publiée avec GitHub Pages.
- Données et documents stockés dans Supabase, accessibles uniquement après connexion par e-mail (liste d'adresses autorisées).
- Ce dépôt ne contient aucune donnée personnelle.
